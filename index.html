        EDU-001critical

        Knowledge-centered architecture

        Knowledge is the center of the design, so the system can’t answer the first question every student asks: what is this for? Without that answer, learning has no direction — for students or for teachers.

        EDU-002high

        Cached response: “it’s useful in life”

        Ask why we study physics or chemistry and teachers and students return the same string. Students check it against their future and conclude it’s false — so they stop learning.

        $ ask student "why learn chemistry?"
< "it's useful in life."
$ ask student "what do you want to do later?"
< "office job."
$ ask student "so?"
< [process disengaged]
        EDU-003high

        Syntax memorization ≠ programming

        Coding gets taught as syntax plus examples. Students nail the obby they were shown, then freeze on the first real project. Code is just a way to talk to a machine, and AI already translates plain English into it. Drilling syntax trains exactly the part that’s being automated.

        EDU-004medium

        Teacher as the only source of truth

        Students wait to be taught part.Touched:Connect instead of reading the docs and asking what :Connect actually is. Learning on your own, the skill that matters most, never gets practiced.

        root cause

        Nobody answered what is school for? before building the school.

        Recommendation: don’t hotfix. Rewrite from intent. ↓

        pass 05 — recovering intent

        Syntax is bytecode.
        Thinking is the source.

        Every pass so far recovered what. This one recovers why — the part school forgets to ship.

        Before you design a school, you have to answer one question: what is school for? My answer: to learn how to learn, to solve problems, and to live well. Every subject, every formula, every line of syntax is a tool for that. It isn’t the point.

        “at its core, school is about learning — and practicing — how to take in knowledge.” — from my notes

        i.

        Code is just a language.

        Code is a way of talking to a computer, the way English is a way of talking to people. Today you can describe what you want in plain words and an AI will turn it into syntax that runs. So why does almost every course start with memorizing syntax?

        ii.

        Thinking doesn’t come from typing.

        It comes from what you do when a problem is hard: when you don’t know the answer and keep thinking until you find one. Someone who really thinks like a programmer could build a whole Roblox game with AI without knowing a word of Lua.

        iii.

        “It’s useful in life” is a bug.

        Students catch that answer fast. Tell them the truth instead: math trains reasoning, and physics and chemistry train you to use reasoning on real problems. Once a student knows what a subject is for, there’s a reason to learn it.

        Students learn.
        Teachers orient.

        “students teach themselves; teachers point the way!”

        pass 06 — lesson 01: variables

        Here’s how I’d teach you.
        No code allowed.

        Most courses open with local x = 5. I’d rather open with a problem: something you can’t solve by remembering, only by thinking.

        The usual exerciseWhat I’d assign
        “Input a. If a > 5, print ‘big’.”Solve a quadratic equation.
        “Input a weight. Print it back.”Build a BMI checker.
        “Print the numbers 1 to 10.”Sort a list.
        “Memorize part.Touched:Connect.”Read the docs. Explain what :Connect actually is.
        “Declare a variable.”Swap two variables. ← try it, right here
        exercise

        Glass a holds red ink. Glass b holds purple ink. Swap them.

        You can only pour into an empty glass. Click a glass to pick it up, then click where to pour it.

        pick up a glass.

        moves: 0

        you just wrote your first program.

        That spare glass has a name in every programming language: a temporary variable. You didn’t memorize it. The problem made you invent it. Learning the syntax takes ten seconds; the thinking is what you keep.

        p.s. Luau lets you write a, b = b, a. That’s a tool, and now you know why it exists.
